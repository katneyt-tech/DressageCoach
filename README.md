# TrueScore AI Coach
Dit project analyseert dressuurtrainingen met AI om objectieve feedback te geven op houding en paard-positie.

## Hoe het werkt:
1. Gebruiker uploadt video vanuit de FlutterFlow app.
2. De Python backend analyseert beelden op loodlijn-afwijkingen.
3. De AI geeft feedback en oefen-advies terug.
